# Look · 使用说明

作者：Leon
版本 1.0.0 ｜ 免安装绿色版 ｜ 全部生成能力走你自己的豆包账号（Seedance），不调用任何第三方 API

---

## 一、这是个什么东西

一句话：**把你电脑上的豆包网页，变成一个能排队的视频工厂。**

- 你手上有 1 个豆包号，它就能跑；有 5 个号，它就让 5 个号同时跑，互不打架。
- 你只要给一张产品图，它自己写提示词、自己点按钮、自己把成片收回来。
- 你也可以完全不用产品图，直接写一段画面描述，让它出图 / 出片。
- 所有账号都登录在你自己的电脑上，多开用的是浏览器的独立分区，**没有服务器中转，没有数据上传**。

**它能做两件事：**

| 模式 | 你给它什么 | 它给你什么 |
|---|---|---|
| **电商视频** | 一张产品图 + 商品名 | 白底主图 → 8 个镜头（15 秒）的竖屏带货片 |
| **其他视频** | 一段画面描述（可选参考图） | 文生图 / 文生视频 / 参考图生图 / 参考图生视频 |

## 二、第一次打开（3 分钟）

### 1. 解压

把整个文件夹解压到一个**你能写文件的位置**，比如 `D:\Look\`。

> ⚠️ 不要放在 `C:\Program Files\`，也不要直接在压缩包里双击。
> ⚠️ 不要只把 exe 拷出来单独放，它需要同目录下的 dll / pak / resources。

### 2. 双击启动

双击 `Look.exe`。

- 打不开的话，双击 `启动（备用）.bat`（它会先打印一行错误原因，再启动）。
- 还是打不开 → 双击 `环境检测与修复.bat`，它会告诉你缺什么。

### 3. 加一个豆包账号

1. 左边栏点 **账号矩阵** → 右上角 **+**（或中间「添加账号」按钮）。
2. 第一次只有一个平台（豆包），直接确认。
3. 右侧舞台会打开豆包的登录页 → **手机扫码登录**。
4. 登录成功后，程序会自动检测到登录态，账号从「待登录」变成「在线」。
   - 这个过程一般 10–30 秒，不用手动刷新。

> 想加第二个号？再来一遍就行。**同一个平台可以加任意多个号**，每个号一个独立分区，登录态不会串。

## 三、做一条电商带货片

### 1. 新建任务

看板上点 **+ 新建任务**（或左上角列表里的同名按钮）。

弹层顶部有两个模式：**电商视频** / **其他视频**。默认是电商视频。

### 2. 填表

| 字段 | 怎么填 | 说明 |
|---|---|---|
| **产品图** | 拖进去，或点一下选文件 | 支持 png / jpg / webp，可多张（第一张当主图）。背景乱没关系，它会先出白底主图 |
| **商品名**（必填） | 例：316 不锈钢保温杯 | 提示词里的主角，写具体型号更好 |
| **品类** | 例：保温杯 / 蓝牙耳机 / 连衣裙 | **决定场景、光线、动作链**。留空会按商品名猜 |
| **目标人群** | 例：通勤白领、学生党 | 决定出镜角色的年龄与穿着 |
| **视频时长** | 15 秒 8 镜（推荐）/ 10 秒 6 镜 / 5 秒 4 镜 | 短档位自动减镜，每镜约 1.3-1.9 秒；不会出现 0.6 秒的假切镜 |
| **卖点** | 例：单手开盖、24 小时保温 | ⚠️ 卖点**只体现在画面里，不会出现文字** |
| **场景** | 例：原木桌面 + 窗边自然光 | 留空按品类自动匹配 |
| **必须保留的本体文字** | 例：杯身 LOGO 与型号 | 商品上的字要保住就写这里 |
| **补充要求** | 例：不要出现人脸 | 可留空 |
| **视频形态** | 自动匹配（推荐）/ 自由构想 / 街拍漫游 / 第一人称 / 手持实测 / 情景段子 / 街头采访 / 穿搭型录 / 美食 ASMR / 硬核实测 / 前后对比 / 居家漫游 / 电影感广告 / 萌宠主角 / 旅拍 / 教程三步 | 「自动匹配」会按商品和卖点挑最合适的，也可以自己指定 |

底部的三个勾选：

- ☑ **不出现字幕** —— 画面里不许有文字、字幕、水印
- ☑ **不出现台词** —— 人物可以动，但不许说话 / 口播
- ☑ **连背景人声也不要** —— 只留环境音或音乐

> 三个默认都勾上。豆包默认爱加字幕和口播，不勾就会被塞进去。

### 3. 开始执行

点 **创建并开始**。任务会出现在左边的列表里，点进去能看到 4 步进度条：

```
① 白底主图  →  ② 提示词  →  ③ 视频生成  →  ④ 验收
```

- **① 白底主图**：把你的产品图重做成纯白底、主体居中的主图，并自动裁掉多余留白。
- **② 提示词**：按品类和形态写 8 个镜头的分镜脚本（含光线、动作、一致性锁、规格）。
- **③ 视频生成**：把提示词发给豆包，等它出片，然后自动下载回来。
- **④ 验收**：**这一步是给你人工看的**。程序不会替你说「可以了」。

### 4. 验收

任务详情里会播放成片。看完：

- 满意 → 点 **通过**，任务变「已完成」，成片进产出库。
- 不满意 → 点 **重跑视频**，可以写一句「哪里不对」（例：人物手部变形 / 镜头太晃 / 商品太小），它带着你的意见再生成一版。
  - 白底主图和提示词会沿用，不用重来。

### 5. 白底主图是怎么处理的（细节）

- 直接把原图和处理要求一起发给豆包（图生图）：去字 / 去水印 → 纯白底 #FFFFFF，并要求主体占画面 **78%–88%**、不许缩小、不许重新构图。
- 出图后本地再做一次归一化：裁掉多余白边，把主体放大到画布 **86%**，长边补到 **2000px**。所以你拿到的处理图构图是统一的。
- 一次拖多张图：程序会在同一个对话里把全部原图一起发过去，让它一次全处理（每张单独出图、不拼图）；批量不成功会自动回退成逐张处理，已经保存好的不会重复消耗额度。

### 6. 豆包停下来问的时候，程序会自己答

| 豆包说什么 | 程序怎么回 |
|---|---|
| 「是否改用非会员模型 / 确认后再生成」 | 自动回一句「确认，直接开始生成」 |
| 「seedance_2.5 当前不可用，请选择 1 或 2」 | 自己挑能力最强的那一档，回对应数字 |
| 已经在排队出片（「预计等待 10 分钟」） | 安静等，不往对话里插话 |

只答一次，不刷屏。每一步都有自校验：缩略图必须出现、提示词必须真的写进输入框、提交必须看到「生成中」或输入框清空；任一步不成立就停下报错并截图，不会闷头等十分钟。

> 想自己盯着豆包页面看？点顶栏的 **看页面**，或者直接点左边某个账号。看完有三种回法：**左侧面板顶部的返回大按钮**、**再点一次刚才那个账号**、或者按 **Esc**。
> 从账号矩阵点进去的，返回后还是**账号列表**（接着点下一个号就行）；从工作台点「看页面」进去的，返回才是工作台。

## 四、做一条「其他视频」（不卖货，纯创作）

弹层里把模式切到 **其他视频**，先选类型：

| 类型 | 需要参考图 | 产出 |
|---|---|---|
| **文生视频** | 不用 | 一段视频 |
| **文生图** | 不用 | 一张图 |
| **参考图生视频** | 必须 | 一段视频（主体跟参考图一致） |
| **参考图生图** | 必须 | 一张图 |

然后填：

- **画面描述**（这段最重要）—— 写清 **场景 / 人物 / 镜头 / 光线 / 情绪**，越具体越准。
  例：*傍晚的老街，一个穿米色风衣的女生边走边回头，霓虹灯牌在雨后地面反光，手持跟拍，浅景深，胶片颗粒。*
- **参考图**（参考类必填）—— 拖图进去。
- **画幅**：竖屏 9:16 / 横屏 16:9 / 方形 1:1 …
- **时长**：视频类型才有，3–60 秒。
- **补充要求**：例「不要出现文字；结尾定格两秒；整体冷色调」。
- **按 Seedance 规范补全镜头结构**（默认勾上）—— 只写一句想法时，程序会替你补齐
  **8 拍镜头结构 + 约束条件 + 画质风格**（结构见下面的「提示词规范」一节），
  主体和主题仍然以你写的那句为准。想看原样的极简请求，把勾去掉即可。
- 三个勾选（不出现字幕 / 不出现台词 / 背景人声也不要）作用同上。

点创建后走 5 步：`① 打开对话 → ② 参考图 → ③ 发请求 → ④ 生成 → ⑤ 回收`。

> 只写了描述、没勾任何东西也能出片，但**豆包默认会加字幕和口播**，做纯画面一定要勾。

## 五、多开：怎么让多个号一起跑

1. 先加够账号（账号矩阵 → +，扫一次码一个号）。
2. 建多个任务，**不用管用哪个号** —— 点开始时程序会自动挑一个当前空闲、在线的号。
3. 一个号同时只跑一个任务；号越多，能并行的任务越多。
4. 号跑完自动回池子，下一个任务接着用。

**额度用完了怎么办？** 账号卡片上会显示「额度用完」，程序会自动跳过它，换下一个空闲号。
实在全用完了，等豆包重置（或换个号）。

## 六、把别的 AI 也做成多开（埋线功能）

这个壳不只服务豆包。**任何能在网页上登录、能对话的 AI**，都能加进来当多开平台：

1. 左边栏 **AI 平台** → 右上角 **+ 添加平台**。
2. 填：
   - **名称**：例 `DeepSeek`
   - **标识**：小写字母 / 数字，例 `deepseek`（不能重复）
   - **对话页地址**：例 `https://chat.deepseek.com/`（**必须是能对话的那一页**）
   - **登录页地址**：一般同上，留空会自动用对话页地址
   - **Cookie 域名**：留空会自动从地址推出来（例 `.deepseek.com`）
3. 保存后，这个平台就出现在「AI 平台」列表里，可以直接 **加账号**、扫码登录、多开。

目前内置深度适配的只有豆包（认得出它的图像 / 视频面板、能自动下载成品）。
其他平台走**通用驱动**：自动找输入框、发送按钮、上传入口、新出现的结果。
个别站点结构特殊，让 AI 改 `resources/app/lib/gen-agent.js` 里的选择器即可（详见 `文档/AI使用说明.md`）。

> 「能让 AI 代写提示词吗？」可以。打开对话让它写，然后把写好的内容粘进任务里就行。

## 九、出问题怎么办（先看这里）

### 打不开

1. 双击 `环境检测与修复.bat`，看它报什么。
2. 确认根目录这几个文件都在：`Look.exe`、`icudtl.dat`、`resources.pak`、`ffmpeg.dll`、`resources\app\index.html`。
3. 被杀软拦了？把整个文件夹加进白名单（程序要下载视频、要操作浏览器，容易被误判）。
4. 还是不行 → 双击 `启动（备用）.bat`，它会显示真实错误。

### 白屏 / 界面错乱

**先分清是哪种白屏：**

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 窗口就是白的，任务管理器里能看到进程 | 上次被**强杀 / 直接关机**，浏览器缓存写坏了（`GPUCache` 里出现 `Invalid file version`），渲染进程一起来就崩 | 直接关掉重开一次即可 —— 程序启动时会发现「上次没正常退出」，**自动清掉缓存**（登录态保留），第二次启动就正常 |
| 重开还是白，并弹出「界面没能加载出来」 | 缓存坏得比较彻底，或程序已经开着一个 | 先确认任务栏 / 托盘里没有第二个窗口；还是不行就点弹窗里的**「重置档案并重启」**，程序会把坏档案改名留档后重启，**账号需要重新扫码** |
| 界面出来了但排版乱了 | 窗口太窄 | 拉到 1200px 以上，或双击顶栏最大化 |

> 想手动处理：双击 `环境检测与修复.bat` → 选「一键修复」（清缓存/分区）；还不行选「深度修复」。
> 坏档案不会被删，会留在程序目录里，名字是 `userdata.损坏备份-时间`，确认没问题可以自己删。

### 卡在某一步不动

1. 点 **看页面**，看豆包页面现在在等什么（是不是在弹「确认生成」、是不是在排队）。
2. 跑一次 **设置 → 开始自检**。
3. 看 `app-run.log` 最后几行。

### 账号老掉线

1. 同一时间别在手机 / 别的浏览器上登同一个号。
2. 重新扫码登录一次。
3. 还是掉 → 环境检测里清一下分区缓存（会要求重新登录）。

### 生成的片子有字幕 / 有人说话

三个勾选项要勾上。勾了还有 → 这是豆包没听约束，用「重跑视频」并写一句「画面里不要任何文字和字幕，不要配音」。

### 想让 AI 帮你修

程序目录的 `文档\AI使用说明.md` 是**写给 AI 看的**：把它 + 一张截图发给任意 AI（豆包、WorkBuddy、ChatGPT 都行），对方就能读懂这个项目并给你改法。
源码全在 `resources\app\` 下，明文，改完关掉程序重开就生效。

## 十、几个必须知道的规矩

1. **用你自己的号。** 程序不提供账号，也不代理任何服务。
2. **别把登录态文件夹发给别人。** `userdata\Partitions\` 里就是你的登录凭证。
3. **生成内容商用前自己确认授权**：素材、肖像、品牌 LOGO 的权属要你自己负责。
4. **平台规则会变。** 豆包改版可能让某一版程序对不上锚点，这时候跑自检、看日志、让 AI 帮你补选择器。
5. **备份 `userdata\`** 就是备份你的所有账号（换电脑直接搬过去，不用重新扫码）。

## 十一、常见问题

**Q：要不要付费？要不要买 API？**
A：不用。全部走你自己豆包账号的免费额度。程序本身免费开源（MIT）。

**Q：会不会封号？**
A：程序做的是「你自己手动也会做的事」，只是自动化了。但任何自动化都有风险，建议：号别太多、别 24 小时不停跑、别跑违规内容。

**Q：能同时跑几条？**
A：等于你在线且有空额度的账号数（一个号同时一条）。

**Q：视频是 9:16 吗？能改横屏吗？**
A：电商默认 9:16 竖屏。「其他视频」里可以选 16:9 / 1:1。

**Q：能不能不用豆包，用别的模型？**
A：可以加平台（见第六节），但「电商视频」那条流水线（白底图 + 4/6/8 镜分镜 + 成品回收）是为豆包深度调的；换平台后能不能跑通，取决于那个平台网页的结构。

**Q：换电脑怎么办？**
A：整个文件夹拷过去，`userdata\` 一起带走，账号就还在。

**Q：源码能改吗？**
A：能，`resources\app\` 下全是明文，MIT 授权，改了关掉重开就生效。

## 十二、提示词是按什么写出来的（可自己改）

程序里所有提示词都由 `resources\app\lib\` 生成，写法依据放在 `resources\app\skills\seedance-prompt\`：

| 文件 | 是什么 |
|---|---|
| `SKILL.md` | 字节跳动官方开源 skill（Seedance 2.0 提示词，v2.0.0） |
| `references/prompt-writing-principles.md` | 官方原则：结构顺序、分镜时序、动作运镜、约束词写法 |
| `OVERRIDE.md` | **本项目自己的标准，优先级最高**：形态引擎、镜头数与节奏、分镜纪律、字幕台词开关 |
| `references/video-formats.md` | 形态库（14 形态 / 18 生活母题 / 54 条真实麻烦 / 品类纠偏表 / 收尾细节表 / 用途判定表），由代码自动生成 |
| `references/third-party-craft.md` | 第三方技法融合记录：从哪些公开仓库提炼了什么、许可与署名、注入到哪一段 |

代码落点：`lib\prompt.js`（四个出口）、`lib\formats.js`（形态 / 母题 / 品类兜底）、`lib\product.js`（商品库）、`lib\craft.js`（第三方技法，按需注入）。

### 本地模板到底做了什么

不是把一段写死的文案填商品名，而是六层拼起来的：

1. **先判断这件商品怎么被用到** —— 14 种形态打分（街拍漫游 / 第一人称 / 手持实测 / 情景段子 /
   街采 / 穿搭型录 / 美食 ASMR / 硬核实测 / 前后对比 / 居家漫游 / 电影感 / 萌宠 / 旅拍 / 教程），
   打分看品类和卖点，前 3 名轮换，重抽换一种拍法。
2. **按片长决定镜头数** —— 15 秒 8 镜、10 秒 6 镜、5 秒 4 镜。5 秒塞 8 镜每镜只有 0.6 秒，
   切不出来，所以自动合并相邻节拍，卖点一条都不少。
3. **开场 3 秒按商品给专属爆点** —— 耳机拍「戴上瞬间噪音被抽走」、吸尘器拍「吸口掠过地面留下干净边界」、
   窗帘拍「拉开时光灌进来」、口红拍「唇上一道显色」。没命中才用形态自己的开场。
4. **商品级纠偏** —— 睡袋不会被当成露营装备（不然会写「穿帐杆、打地钉」），
   洗面奶不会显示「通用商品」，猫窝的麻烦是「买回来它不睡」而不是「饿了一天」。
5. **用途写死一句话** —— 提示词里那段「它是做什么的」决定模型怎么用这件东西：
   鱼缸过滤器是「装在水里循环水」不是喂食器、泳装是「真的下水」不是岸上摆拍、
   美缝剂是「挤进缝里刮平」不是擦脏东西。这条判断优先用商品级覆写，其次按名字查表，
   卖点只作最后兜底（「保温」这种词会把任何商品判成杯子）。
6. **参考图与真实感按形态给具体拍法** —— 参考图拆成「必须继承 / 不得继承 / 跨镜保持」三段，
   不是一句「保持一致」；真实感落到可执行的细节：手持形态写抖动、对焦呼吸、曝光浮动，
   美食写食材变化与对应声音，广告写光位与材质特写，还会给运镜与景别词表、以及该形态的避坑。
   这些来自公开仓库的技法，只在形态匹配时才注入，不会把几十条规则堆到每一条片子上。

### AI 代写又是什么

「AI 代写」不是换一套标准，是把同一份要求交给豆包写分镜正文：
镜头数、参考图说明、卖点要落到动作、分镜纪律、真实感清单、一致性锁、**用途说明**，逐条和本地模板对齐。
任务书里还有一段「来自 Seedance 技法的补充要求」，把上面第 6 层的技法同样交代给豆包——
否则本地模板越来越细，AI 代写还是老样子。
两边的「它是做什么的」必须是同一句——各取一套就会出现「模板说是婴儿睡袋、任务书说是户外装备」。
台词类技法跟着「不出现台词」那个勾走：勾上就不教怎么写台词，也不会一边禁台词一边要求写台词。
豆包写砸了（太短、拒答、没有镜头词）会自动回退本地模板，不会卡住出片。

两种方式都能用，区别只是「分镜正文由谁写」：本地模板稳定可复现，AI 代写更灵活偶尔更出彩。

### 改完怎么自检

```bat
cd resources\app
node _t\cover.js          :: 69 个全类目样本，要求「未识别品类 = 0」
node _t\check-prompt.js   :: 252 组提示词 + 30 组全形态矩阵 + 极端输入，0 错误才算改完
                          :: 顺带查「用途说明两边不一致」「开场钩子跑偏」
                          :: 以及「技法表失配」（改了形态名但技法没跟，等于静默失效）
node _t\gen-formats-doc.js > skills\seedance-prompt\references\video-formats.md
```

> 这些命令要装 Node.js 才能跑；不装也能正常用程序，只是改完没法自检。
