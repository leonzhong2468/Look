## 4. 自由构想：生活母题（`MOTIFS`）

「不套模板」模式先挑一个生活场景，再按卖点挑一件真实会发生的小麻烦。

### 通勤路上（`commute`）

- 适用品类：digital / drinkware / apparel / eyewear / office / jewelry
- 开场：早高峰的地铁门刚开，人往车厢里挤
- 环境：早高峰地铁 / 换乘通道 / 写字楼电梯间，冷白顶光混着手机屏的光
- 人物：一个赶时间的上班族，肩上挂着包，手上还拿着咖啡
- 商品出场：在挤得站不稳的车厢里，单手把它拿出来用
- 收尾：车门开，人流出站，画面跟着走出去

### 居家清晨（`morning`）

- 适用品类：beauty / drinkware / kitchen / home / health / appliance / garden
- 开场：闹钟刚被按掉，房间里还拉着窗帘
- 环境：出租屋 / 主卧洗手台 / 厨房，清晨侧光从窗帘缝进来
- 人物：刚起床的人，头发乱、素颜、穿家居服
- 商品出场：洗漱间隙顺手用一下
- 收尾：收拾好出门，画面停在收拾干净的台面

### 下厨出餐（`kitchen`）

- 适用品类：kitchen / food / home / drinkware / appliance / garden
- 开场：锅里的油刚开始响，抽油烟机嗡嗡的
- 环境：家用厨房，灶台上方的暖光，台面有水渍和菜叶
- 人物：正在做饭的人，围裙、袖子挽起来
- 商品出场：一边看火一边用它
- 收尾：端着做好的东西离开灶台

### 朋友来家里（`friends`）

- 人物：主人和两三个朋友，穿着随意
- 商品出场：当着朋友的面拿出来用

### 周末户外（`weekend`）

- 环境：车内副驾 / 服务区 / 山路边停车带，日光强，玻璃有反光
- 人物：开车的人和副驾的人，穿得舒服
- 商品出场：在车上或车边用它
- 收尾：发动车，画面前进

### 桌面工作流（`desk`）

- 适用品类：digital / office / drinkware / tool
- 开场：键盘敲到一半，手伸向桌角
- 环境：书桌 / 咖啡店靠窗位，侧光，桌上有便签和线缆
- 人物：在电脑前坐了半下午的人
- 商品出场：工作间隙顺手用
- 收尾：合上电脑，画面停在桌面

### 街头随手拍（`streetlife`）

- 适用品类：apparel / eyewear / jewelry / digital / beauty
- 开场：路边店铺的招牌灯刚亮，行人从镜头前走过
- 环境：老街 / 商圈人行道，傍晚的自然光加店招光
- 人物：一个走在街上的人，穿得有型但不夸张
- 商品出场：边走边用，脚步不停
- 收尾：拐进巷子，画面跟丢又追上

### 海边度假（`beach`）

- 适用品类：apparel / sports / travel / beauty / eyewear
- 开场：海风把遮阳伞吹得有点歪，脚底下是烫的沙
- 环境：海边浅滩 / 泳池边，下午的直射光，水面是细碎反光
- 人物：两三个年轻人，穿泳装或外面罩着宽松衬衫，皮肤上有水痕和沙
- 商品出场：从水里上来，或者正要下水
- 收尾：坐回沙滩巾上，背景是没停过的浪

### 下雨天（`rainy`）

- 适用品类：apparel / eyewear / digital / car / home
- 开场：雨点砸在窗玻璃上，行人开始跑
- 环境：写字楼门口 / 街边屋檐 / 地铁口，湿地面反光
- 人物：没带伞或刚收伞的人，头发有点湿
- 商品出场：在雨里或雨停后用它
- 收尾：雨小了，画面停在湿漉漉的地面

### 家务时刻（`chores`）

- 适用品类：home / appliance / kitchen / garden / pet / maternal
- 开场：洗衣机刚停，阳台地上还堆着没收的衣服
- 环境：家里阳台 / 客厅 / 卫生间，白天的自然光，地面有水痕和灰
- 人物：一个人在家收拾，穿家居服，手机架在旁边放歌

### 动手修东西（`diy`）

- 适用品类：tool / home / car / appliance / garden

- 环境：家里要修的角落 / 车库 / 阳台，顶灯加一束手电的侧光
- 人物：袖子挽起来的人，手上已经有点脏
- 商品出场：蹲下来 / 站上去，对着那个位置动手
- 收尾：退后一步看成果，手上的灰还没擦

### 阳台园艺（`garden`）

- 适用品类：garden / home
- 开场：清晨的阳台，叶子上还挂着一层水汽

- 人物：穿家居服、手里还端着水杯的人
- 商品出场：蹲下来摆弄那几盆
- 收尾：站起来看整排，光正好落在叶子上

## 8. 定格收尾细节（`END_BIT`）

最后 0.8 秒定格时"还在动的小细节"按品类取，写死一个通用部件会在别的品类上落到根本不存在的结构上（婴儿睡袋收在"滚轮/指示灯"就是这么来的）：

## 9. 用途判定（`PURPOSE_HINTS`）

提示词里的「它是做什么的」判错，模型就会按错误用法拍：睡袋被当成帐篷、花洒被当成水龙头、
鱼缸过滤器被当成喂食器。优先级是 `REFINE.purpose`（商品级覆写）→ 名字匹配下表 → 卖点兜底。

| 命中词 | 用法说明 |
|---|---|
| `车贴|车身贴|拉花|车标|车内装饰` | 贴在车身或车窗上的装饰贴，用之前要先把位置擦干净、撕下背胶、从一边慢慢压平（不能拍成贴在桌面或贴在人身上） |
| `纹身贴|身体贴|临时贴` | 贴在皮肤上的临时图案，用湿毛巾按压几十秒再撕纸，贴在手腕、手臂或脚踝（不是真的纹身，也不是贴在衣服上） |
| `墙贴|墙纸|壁画` | 贴在墙面上的装饰，用之前把墙面擦干净，从一角开始向另一侧赶气泡 |
| `冰箱贴|徽章|立牌|摆件` | 摆着看的装饰小物，吸附或立在平面上的固定位置，靠造型和质感出效果 |
| `泳装|泳衣|比基尼|连体泳|分体泳|沙滩裤|潜水服` | 穿在身上下水的泳装，用的时候是人真的入水、游动、上岸，看的是贴身、速干和在水里的样子（不是当日常内衣穿，也不是只在岸上摆拍） |
| `被子|被芯|羽绒被|蚕丝被|毛毯|毯子` | 盖在身上保暖的被子，用之前要抖开、铺平，盖的时候看的是蓬松度、垂坠和贴身感 |
| `地毯|地垫|地席` | 铺在地面上的织物，用之前先卷开、抚平，看的是踩上去的厚度、纹路和是否打滑 |
| `凉席|床垫|床笠|四件套|床品|枕` | 铺在床上的用品，用之前先铺好、拉平边角，看的是贴合、透气和翻身时的服帖 |
| `窗帘|遮光帘|纱帘` | 挂在窗上的布，用的时候是拉开 / 拉合，看的是遮光、垂感和轨道顺滑 |
| `婴儿推车|遛娃|安全座椅|婴儿床|餐椅` | 带娃出行或安放宝宝的用具，用的时候是展开、把娃放进去、推着走或固定好、再收起来，看的是推行顺滑、稳当和收折方便 |
| `杯|壶|保温|吸管` | 装水或饮料的容器，用之前先打开盖子，喝的时候杯上、手上都没有盖 |
| `锅|炒锅|煎锅|奶锅|蒸锅` | 放在灶上加热食物的锅，用之前先放稳、开火，食物在锅里翻动才说明它好用 |
| `刀|砧板|削皮|锅铲|勺` | 处理食材的厨具，用之前先就位，动作是切、削、铲、盛，不是空挥 |
| `餐具|碗|盘|碟|筷` | 盛放食物的餐具，用的时候装着真实的食物，看的是容量、手感和易清洗 |
| `鱼缸|水族|滤材|增氧|潜水泵|水循环` | 装在水里的过滤与循环设备，用之前先按水位装好进出水口、通电，让水循环起来（不是喂食器，也不是给人喝的） |

| `插排|插座|转换器|数据线|充电` | 接电或充电的配件，用之前先插到底，看的是接触稳、不发烫、线不乱 |
