# 发布流程（从零到 GitHub Release）

> 这份文档写给**维护者**。目标：改完代码 → 打出绿色版 zip → 发到 GitHub Releases，全程不超过 10 分钟。

---

## 0. 一次性准备

| 需要 | 说明 |
|---|---|
| Node.js 18+ | 只用来下载 Electron 运行时 |
| Electron 运行时 | 下载 `electron-v43.x-win32-x64.zip` 并解压，例如放到 `D:\electron-v43-win32-x64\` |
| rcedit-x64.exe | 用来改 exe 图标与版本信息：[electron/rcedit releases](https://github.com/electron/rcedit/releases) |
| Git | 提交与推 tag |

Electron 运行时下载地址：
`https://github.com/electron/electron/releases` → 找 `electron-vXX-win32-x64.zip`（**不要**下 `symbols` 或 `dsym`）

---

## 1. 改版本号

三处要同步：

1. `src/package.json` → `"version": "1.0.1"`
2. `src/index.html` → 顶栏品牌旁边的版本角标（`v1.0.0` 那串）
3. `src/renderer.js` → 如果界面某处硬写了版本，一起改

---

## 2. 自测（必做，别跳）

```bash
cd src
npm start
```

检查清单：

- [ ] 窗口能打开，不白屏
- [ ] 账号矩阵能加账号、能扫码、能识别登录态
- [ ] 新建任务弹层：电商 / 其他视频两种模式都能切换
- [ ] 电商模式拖图、填商品名能创建任务，步骤条会往下走
- [ ] 其他视频四种类型都能选，参考图类型必须能传图
- [ ] 三个勾选（不出现字幕 / 台词 / 背景人声）会写进提示词
- [ ] AI 平台页能加自定义平台（填 DeepSeek 的地址试一次）
- [ ] 产出库、设置、关于页都正常
- [ ] DevTools Console 没有红色报错

再跑一次语法检查（防止手滑）：

```bash
for f in main.js preload.js renderer.js task-ui.js support.js lib/*.js; do node --check "$f" || echo "SYNTAX FAIL: $f"; done
```

---

## 3. 打发布包

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1 `
  -ElectronDir "D:\electron-v43-win32-x64" `
  -Version 1.0.1
```

脚本会：

1. 复制 Electron 运行时到 `release\stage-1.0.1\`
2. 把 `src\` 放进 `resources\app\`（**不打 asar**，保持源码可改）
3. 把文档放进 `文档\`，把 doctor.ps1 / bat 放进 `tools\` 与根目录
4. 把 `electron.exe` 重命名为 `Look.exe`
5. 用 rcedit 写图标与版本信息
6. 打 zip 到 `release\Look-v1.0.1.zip`

打完之后**必须**验证一次：

```powershell
# 解压到临时目录，双击启动
Expand-Archive release\Look-v1.0.1.zip -DestinationPath $env:TEMP\rel -Force
& "$env:TEMP\rel\Look.exe"
```

- [ ] 能启动、有窗口、图标是紫青渐变那个
- [ ] 右键 exe → 属性 → 详细信息：产品名 / 版本 / 作者都对
- [ ] `环境检测与修复.bat` 报 0 异常

---

## 4. 提交与打 tag

```bash
git add -A
git commit -m "release: v1.0.1

- 修：...
- 增：...
"
git tag -a v1.0.1 -m "v1.0.1"
git push origin main --tags
```

---

## 5. 发 Release

1. 仓库 → **Releases** → **Draft a new release**
2. **Choose a tag** → 选刚推的 `v1.0.1`
3. **Release title**：`v1.0.1`
4. **描述**（模板见下）
5. **Attach binaries** → 上传 `Look-v1.0.1.zip`
6. **Publish release**

### Release 描述模板

```markdown
## 这一版改了什么

**新增**
- 其他视频支持「参考图生视频」，主体一致性更好
- AI 平台可以自己加 Cookie 域名

**修复**
- 修：白底图偶尔偏灰
- 修：长任务跑完不刷新状态

**已知问题**
- 豆包改版后视频面板锚点可能失效，跑「设置 → 开始自检」后按提示修

---

### 怎么用

1. 下载下面的 zip
2. **完整解压**到可写目录（别放 C:\Program Files）
3. 双击 `Look.exe`
4. 账号矩阵 → + 添加账号 → 扫码

打不开先双击 `环境检测与修复.bat`。

### 校验

SHA256: `（把 zip 的哈希贴这里）`
```

生成哈希：

```powershell
Get-FileHash release\Look-v1.0.1.zip -Algorithm SHA256
```

## 6. 发完之后

- [ ] 在 README 的下载链接上确认指向最新 Release
- [ ] 群里 / 朋友圈发一句更新说明（别只发链接，说清改了什么）
- [ ] 保留上一个版本的 zip（有人会回退）

## 附：版本号怎么定

| 改动 | 用 | 例 |
|---|---|---|
| 只改文档 / 提示词措辞 | PATCH | 1.0.0 → 1.0.1 |
| 加功能、改界面 | MINOR | 1.0.1 → 1.1.0 |
| 大改架构 / 不兼容旧数据 | MAJOR | 1.1.0 → 2.0.0 |

## 附：常见打包坑

| 现象 | 原因 | 处理 |
|---|---|---|
| exe 启动报 `Invalid file descriptor to ICU data` | `icudtl.dat` 没一起复制 | 确认发布包根目录有 `icudtl.dat` |
| 启动后白屏 | `resources/app/index.html` 缺失，或 asar 打进去了 | 不要用 asar，源码要能在 `resources\app` 里直接看到 |
| 图标还是 Electron 默认的 | rcedit 没跑 / ico 路径错 | 手动跑一次 rcedit，确认 `--set-icon` 指向 `src\app.ico` |
| 被杀软删文件 | 未签名的 Electron 程序常被误判 | 让用户加白名单；有条件可做代码签名 |
| 用户双击没反应 | 从压缩包内直接运行 | 文档里反复强调「先完整解压」 |
