# 常见问题（FAQ）

## 一、安装与启动

### 双击 exe 没反应 / 一闪就消失

按顺序排查：

1. **是不是在压缩包里双击的？**
   必须先把 zip **完整解压**，再运行里面的 exe。

2. **是不是只拷了 exe 出来？**
   这个程序需要同目录下的 `icudtl.dat`、`resources.pak`、一堆 dll，以及整个 `resources\app\` 文件夹。单独一个 exe 起不来。

3. **跑环境检测**
   双击 `环境检测与修复.bat`，它会明确告诉你缺什么。

4. **被杀软拦了**
   未签名的 Electron 程序容易被误判（尤其是要下载视频、要操作浏览器）。把整个文件夹加入白名单。

5. **尝试备用启动**
   双击 `启动（备用）.bat`，它会清掉可能干扰的环境变量并打印真实错误。

### 提示 `Invalid file descriptor to ICU data received`

缺 `icudtl.dat`。解压不完整 → 重新解压一次。

### 窗口打开了但一片空白

1. 按 `Ctrl+Shift+I` 打开 DevTools，看 Console 第一条红字
2. 检查 `resources\app\index.html`、`style.css`、`renderer.js` 是否存在
3. 如果你改过代码 → 改出语法错误了，`node --check` 检查一遍

### 能不能装在 C:\Program Files？

不建议。程序要把账号、缓存、成品写在**自己所在目录**，`Program Files` 默认只读。
装在 `D:\Look\` 这种普通目录最稳。

## 二、账号

### 扫码后一直显示「待登录」

1. 等 30 秒（登录态检测是轮询的）
2. 点账号卡片，看右侧页面是不是已经进了对话界面
3. 还是不行 → 删掉这个账号重加一次

### 账号经常掉线

1. 同一时间别在手机 / 别的浏览器登同一个号（会把网页端的登录挤掉）
2. 重新扫码
3. 网络或代理变化也会掉，尤其挂梯子的时候

### 换电脑怎么搬账号？

把整个文件夹拷过去，**`userdata\` 一定要带上**（里面有 `accounts.json` 和每个账号的浏览器分区）。搬过去直接能用，不用重新扫码。

### 能加多少个号？

技术上没有限制。实际取决于你的电脑内存（每个账号一个浏览器视图，常驻会吃内存）和平台自己的规则。建议 3–10 个。

### 想用别的 AI 平台（DeepSeek / WorkBuddy / Kimi…）

界面「AI 平台 → + 添加平台」，填：

- 名称：随便写
- 标识：小写字母数字，不能重复
- 对话页地址：**能直接对话的那一页 URL**
- 登录页地址：一般同上
- Cookie 域名：留空会自动推断

保存后就能「加账号」，走通用驱动。

## 三、生成

### 卡在「① 白底主图」

1. 点顶栏「看页面」，看豆包页面在干嘛（是不是在等上传、是不是弹了提示）
2. 跑「设置 → 开始自检」
3. 看 `app-run.log` 最后 30 行

### 卡在「③ 视频生成」很久

视频生成本身就慢（1–5 分钟很正常），另外：

- 豆包可能在弹「确认生成」（额度 / 时长确认）→ 看页面能看到
- 账号额度用完了 → 换号
- 高峰期排队

### 生成的视频里有字幕 / 有人说话

三个勾选项（不出现字幕 / 不出现台词 / 背景人声也不要）**默认已勾**。如果还出现：

1. 用「重跑视频」，在修正意见里写：`画面里不要出现任何文字和字幕，不要配音，只要环境音`
2. 这是模型没听约束，不是程序 bug；多试一次通常就好

### 商品上原来的 LOGO / 文字被改掉了

在「必须保留的本体文字」里写清，例：`杯身 LOGO 与型号字样必须保持原样`。

### 白底主图主体太小 / 四周留白多

程序会自动裁主体并补纯白。如果还是不满意，用「重跑视频」前先在豆包里手动换一张更规范的原图（纯色背景、主体占画面 60% 以上）。

### 一次能跑几条？

等于「在线且有空额度的账号数」，一个号同时一条。

## 四、产出与文件

### 成片存在哪？

`downloads\<任务id>\`。界面「产出库」也能看。

### 删了 userdata 会怎样？

账号全丢，要重新扫码。任务历史也没了。**删之前先备份。**

### 日志会不会无限变大？

超过 1MB 会自动重开。环境检测工具里也能一键归档。

## 五、开发与改造

### 源码在哪？能改吗？

`resources\app\` 下全是明文 JS / HTML / CSS，MIT 授权，随便改。改完关掉程序重开就生效。

### 为什么不用 asar 打包？

故意的。用户要能直接打开改，平台改版时自己（或让 AI）补一行选择器就修好了。加编译步骤就失去了这个能力。

### 怎么让 AI 帮我修？

把 `文档\AI使用说明.md` 整份 + 一张截图发给任意 AI，它能读懂项目结构、知道该改哪个文件。

### 加一个新平台要改代码吗？

不用。界面里加就行。只有当那个网站结构特别怪、通用探针找不到输入框时，才需要改 `lib\gen-agent.js` 里的选择器。

### 我能二次分发 / 商用吗？

MIT 允许。但请保留作者署名与免责声明。修改版出问题由修改者负责。

## 六、安全与合规

### 会不会上传我的数据？

不会。程序没有中转服务器，不上传账号、提示词、生成内容。所有数据都在你硬盘上。

### 会不会封号？

程序做的是「你自己手动也会做的事」，只是自动化了。任何自动化都有风险，建议：号别太多、别 7×24 跑、别碰违规内容。

### 生成的内容能商用吗？

取决于平台条款和素材授权。**商用前请自行确认**：素材版权、人物肖像、品牌 LOGO 使用授权。

### `userdata\Partitions\` 是什么？

每个账号的浏览器登录凭证。**等同于你的账号密码**，不要发给别人、不要传到网盘。
